But du jeu :
Vous devez gagner le plus de points. Vous allez parier le nombre de plis que vous allez faire..
Calcul des points :
  • 0 plis parier : +/- 10 * le nombre de carte au début de la manche (au tour 5, on joue pour +/- 50 points)
  • autre plis :
    • bon pari : + 20* le nombre de plis pariés
    • mauvais pari : - 10* le nombre de points d'écarts entre le pari et le résultat (ex : 2 plis pariés mais 5 récupérés, 5 - 2 = 3 3*10 = 30. Vous perdez 30 points)
Mise en place :
Distribuer une carte à chaque joueur. Indiquer le nombre de plis que vous allez faire (0 ou 1).
Jouer la cartes dans l'ordre. Compter le nombre de plis réalisé (rien ou 1) puis recommencer avec une carte de plus à chaque tour
Comment jouer :
Vous devez forcément mettre la première couleur demandée.
Si vous n'avez pas la couleur demandée, vous pouvez mettre ce que vous voulez.
Les cartes sans couleur (drapeau / tigresse / sirène / pirate / Skull King) peuvent être jouées n'importe quand.
En cas d'égalité sur les cartes de valeur, le premier joueur à avoir posé la carte la plus haute l'importe.
Si un drapeau blanc est posé, la couleur est déterminée par le joueur qui joue après.
Si le skull king, le pirate et la sirène sont joués pendant le même tour, la sirène l'emporte
